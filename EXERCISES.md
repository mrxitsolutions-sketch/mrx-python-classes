# Practice exercises

## Numbers and strings

Read a fictional item name and quantity and build a one-line receipt entry. Try blank text, a value with spaces and a negative number.

## Functions and collections

Write a function that converts distances to metres. Make a second function that takes a list of conversions and counts them by unit.

## Exceptions and files

Read lines from a scratch text file. Keep valid numeric entries and collect invalid lines with their line numbers.

## JSON and dictionaries

Save a set of fictional library loans as JSON, reload it and check for fields missing in individual records.

## Object design

Model a library loan with checkout and return operations. Decide what should happen when the same loan is returned twice.

## Iterators and generators

Write a generator that yields only matching rows from a small table. Confirm what happens after the generator is exhausted.

## SQLite

Create an in-memory table for invented book records and query available titles, counts and loans by status.

## Tkinter and data

Put a label, entry and button in a resizeable window. For a separate statistics exercise, compare the mean and median of a small synthetic dataset before and after adding an outlier.
