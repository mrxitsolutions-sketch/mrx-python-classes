# Python Classes and Practice outline

Use this sequence to navigate the Python classroom materials by topic.

## Teaching sequence

- Printing, input, types, strings and basic control flow
- Functions, arguments, lists, tuples, dictionaries and sets
- Exceptions, modules, file I/O, JSON and recursion
- Classes, inheritance, properties, iterators and generators
- SQLite, relational database concepts, Tkinter and data-analysis practice
- Optional follow-on reading in web development, statistical exploration and machine learning
